# Word 文档故障排查（症状 → 修复）

按"用户看到的现象"查表。修复动作都是**改 Doc JSON / 改 ops 后重新导出**，改完必须复验。

## 打开文件提示损坏 / 修复

- **可能原因**：导出被中断；路径不是 .docx；文件被外部程序占用。
- **修复**：确认 `write_docx` 成功返回"已写入"；用 `read_docx` 读回验证——能无损读回说明包结构完整；用 `read_file` 看文本视图。仍打不开则重新导出一次（覆盖写）。

## 标题看起来和正文一样（没有层级）

- **可能原因**：块类型用了 `paragraph` 而不是 `heading`；或 heading 的 level 没写/全写 1。
- **修复**：改 `{"type":"heading","level":N,"text":…}`；检查 H1→H2→H3 递进（跳级也会让 Word 导航栏混乱）。

## 图片不显示（红叉/空白）

- **可能原因**：src 路径不存在（最常见——编造了路径）、格式不支持、文件过大。
- **修复**：先 `list_files` 确认图片真实存在于工作区；改用存在的路径或 `download_file` 下载；>10MB 的图先压缩；svg 源文件可直接引用（自动栅格化）。

## 表格列宽错乱 / 内容溢出

- **可能原因**：列数太多（>20）或单元格内容超长；数据行数与表头不一致。
- **修复**：拆表或只列关键指标；短句入格；确认 headers 与 rows 列数一致（报错会提示）。

## 公式显示成代码或变成图片缺失

- **可能原因**：`$...$` 语法没被解析（写成了普通文本或格式不对）。
- **修复**：确认行内公式用 `$公式$`（如 `$E=mc^2$`），块级大公式也用它；LaTeX 语法错误会回退为纯文本，检查括号/转义。

## 目录打开后没显示页码/页码不对

- **说明**：我们生成的是 **Word TOC 域**（章节列表），不是打开即已填好页码的静态文本。用户要求"目录页码对"时，请说明：在 Word 里右键目录 →"更新域"即可生成/刷新页码；或去掉 toc 改用正文结构导航。
- **修复**：章节标题必须用 `heading` 块（目录依赖它生成）；改了标题后重新导出。

## 中文变成乱码/方块

- **可能原因**：文本编码问题极少见（导出固定 UTF-8）；更可能是用了系统没有的字体名——我们固定用宋体/黑体，不接外部字体。
- **修复**：确认块内文本正常；重新导出。若用户指定了特殊字体要求，说明"当前版本固定系统字体，无法指定第三方字体"。

## 用户要的版式做不出来（页眉页脚/批注/修订/脚注）

- **说明**：这些不在能力边界内（见 SKILL.md）。**不要假装支持**。
- **修复**：明确告知不支持并给替代：页眉页脚→封面/标题区文字说明；脚注→括号注；批注→正文加"注："段落；修订→直接改内容（不保留修订痕迹）。

## 样式不对（颜色/字体层级不是用户想要的）

- **修复**：`edit_docx` 传 `{"op":"set_style","style":"default|academic|minimal"}` 换预设；正式文档选 default，学术选 academic，内部备忘选 minimal。

## 修复已有 docx 的标准工作流（参考 qwenwork/workbuddy docx 修复类能力）

1. **先读后改**：`read_docx(path)` 拿当前 Doc 结构（标题/章节/块顺序/表格/图片）。
2. **定位问题**：按用户反馈列出具体问题（哪一章、哪一段、哪个表格：内容错/层级乱/格式不对/占位符未填）。
3. **小改**：用 `edit_docx` 改单块 `update_block`、增删块 `add_block`/`delete_block`、移动块 `move_block`、全局改词 `replace_text`、换样式 `set_style`。
4. **占位符**：`{{字段}}`/`【待填】`/`TODO` 用 `replace_text` 逐个替换，替换后读回确认没有残留。
5. **复验**：`read_docx` 抽查目标区域和相邻章节，确认没有破坏其它内容。
6. **大改重导**：结构性问题分散时，直接改 Doc JSON 后重新 `write_docx`（保留 doc.json 源文件），不要逐块硬修。

# PPT 故障排查（症状 → 修复）

按"用户看到的现象"查表。修复动作都是**改 Deck JSON / 改 ops 后重新导出**，改完必须复验受影响页。

## 文件打不开 / 提示损坏

- **可能原因**：导出被中断；路径不是 .pptx；被外部程序占用。
- **修复**：确认 `write_pptx` 成功返回；`read_ppt` 能无损读回说明包结构完整；仍打不开则重新导出一次。

## 文字溢出页面 / 内容被截断

- **可能原因**：要点太多（>7 条）或单条过长；custom 版式坐标/字号设置不当。
- **修复**：拆页或压缩为 3~5 条短要点；custom 元素改小字号或调整坐标（x/y/w/h 0~1 相对值，注意叠加）。

## 图表数据不对 / 显示空白

- **可能原因**：chart 的 categories/series 结构错误（values 数与 categories 不一致）；数值过大（单位不匹配）。
- **修复**：确认 `series[].values` 长度 = `categories` 长度；数据来自工作区资料；单位统一（用百万/亿时写进标题）。

## 图片不显示（红叉/空白）

- **可能原因**：src 路径不存在（最常见——编造了路径）、格式不支持、文件过大。
- **修复**：先 `list_files` 确认图片真实存在于工作区；>10MB 先压缩；svg 可直接引用（自动栅格化）；照片用 `download_file` 下载。

## 字体看起来不对

- **说明**：固定用系统字体渲染（中文 Microsoft YaHei 系/黑体、西文 Arial 系）；不支持指定第三方字体或嵌入字体。
- **修复**：用户指定字体时说明"固定系统字体"；样式问题（大小/粗细/颜色）由版式与主题控制，换 theme 或改 custom 元素。

## 主题色不是用户想要的

- **修复**：`edit_ppt` 传 `{"op":"set_theme","theme":"…"}` 换 8 套预设之一；自定义色板语法见 `reference/themes.md`（`{"op":"update_slide",…}` 或重建时 deck 带 theme 字段）。

## 用户要的效果做不出来（动画/音视频/母版定制/图表二次编辑）

- **说明**：不在能力边界内（见 SKILL.md）。**不要假装支持**。
- **修复**：明确告知不支持；图表改数 → 改 deck 的 chart 数据重新导出（数据内嵌只读）；演示节奏 → 用分节页和 notes 组织讲稿。

## 外来 pptx 仿制后"不像原文件"

- **说明**：外来文件是近似导入（文本/表格/版面保留，图片与图表数据不保留，样式细节丢失），重建必然与原版有差异。
- **修复**：重建前先 `read_ppt` 分析结构；对照原文件补齐图表/图片（从工作区素材或 read_ppt 的文本重建数据）；向用户说明近似导入的边界。

## 修复已有 pptx 的标准工作流（参考 qwenwork/workbuddy pptx 修复类能力）

1. **先读后改**：`read_ppt(path)` 拿当前 Deck 结构（页面/标题/要点/主题）。
2. **定位问题**：按用户反馈列出具体问题（哪一页、什么现象：文字溢出/顺序错/内容错/主题不对）。
3. **小改**：用 `edit_ppt` 单页改 `update_slide`、全局改词 `replace_text`、换主题 `set_theme`、调备注 `set_notes`。
4. **结构调整**：增删移页 `add_slide`/`delete_slide`/`move_slide`；顺序大改建议读回 deck 后重建。
5. **复验**：`read_ppt` 抽查受影响页和全局，确认没有破坏其它页。
6. **大改重导**：如果问题分散在多数页面，直接改 Deck JSON 后重新 `write_pptx`（保留 deck.json 源文件），不要逐页硬修。

## 长 deck 回读后按页修复（参考 Doubao ppt 回读定位）

- **回读先对页序**：`read_ppt` 读回后按顺序核对“期望页码 ↔ 实际标题/内容”，页数相同、无报错不能代替页序验收。
- **不要凭记忆改 index**：`edit_ppt` 的 index 以最新 `read_ppt` 返回的 slides 顺序为准；每次修复前重新读回一次，避免在旧页序上计算 index。
- **补页/插页先定位锚点**：要插到某页之前，先用 `read_ppt` 确认目标页当前 index，再用 `add_slide` 的 `index` 插入；定位失败不要退化为末尾追加。
- **修复后复验受影响页与相邻页**：页序修复后抽查被移动页前后各一页，确认没有重复/丢失；内容修复后抽查该页文字与图片引用。

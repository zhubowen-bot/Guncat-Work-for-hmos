# Excel 数据分析玩法（Analysis Playbook）

面向"从数据到结论"的分析任务：在 Workbook JSON 能力内，用 sheet 结构 + 公式完成常见分析，再配合 `read_xlsx` 验证。
**所有分析必须基于工作区真实数据**；没有数据就向用户要，不编造数字。

## 通用分析框架

1. **定问题**：用户要回答什么决策？（趋势/对比/构成/异常/敏感性）
2. **找数据**：工作区 CSV/JSON/xlsx 用 `read_file`/`read_xlsx` 读；大文件先 `transform_file` 清洗。
3. **建结构**：按分析类型选 sheet 结构（明细 + 汇总 + 口径）。
4. **写公式**：派生值全部公式；假设集中放"假设"sheet。
5. **验证与交付**：`read_xlsx` 抽查关键值；对话给结论，不只丢文件。

## 1. 趋势分析

适合：收入/用户/成本随时间的变化。

```
Sheet「明细」
  日期 / 指标值
Sheet「趋势」
  月份 / 值 / 环比 / 同比 / 3期移动平均
  环比：=(B3-B2)/B2（percent）
  同比：=(B3-C2)/C2（percent；需去年同月列）
  移动平均：=AVERAGE(B2:B4)
```

- 日期列用 `date` 或统一文本；排序按时间升序。
- 需要可视化时用 ppt 技能 chart 页，xlsx 内不做图表。

## 2. 对比分析

适合：预算 vs 实际、区域/渠道对比、本期 vs 上期。

```
Sheet「对比」
  维度 / 本期 / 上期 / 差异 / 变化率
  差异：=B2-C2
  变化率：=IF(C2=0,"—",(B2-C2)/C2)（percent）
```

- 分母为 0 时用 `IF(C2=0,"—",…)` 避免除零。
- 维度排序按差异绝对值，突出最重要变化。

## 3. 构成分析

适合：占比、结构、贡献度。

```
Sheet「构成」
  项目 / 金额 / 占比
  占比：=B2/$B$10（percent；$B$10 为合计行）
```

- 分母锁定合计行（绝对引用 `$B$10`）；项目 ≤10 个，超过合并"其他"。
- 饼图等可视化交给 ppt 技能 chart。

## 4. 异常归因

适合：指标突增/突降、离群值、Top 贡献者。

```
Sheet「明细」：原始数据
Sheet「异常检查」
  筛选条件或检查公式：=IF(B2>AVERAGE(B:B)+2*STDEV(B:B),"异常","正常")
  维度贡献：=B2/SUMIF(维度列,维度值,数值列)
```

- 先用 `transform_file` 清洗/排序找极值，再在 Excel 里建检查公式。
- 结论必须给出可能原因和待验证假设，不能只报数字。

## 5. 敏感性分析

适合：价格/销量/成本变化对利润的影响。

```
Sheet「假设」
  基准值：单价/销量/变动成本率/固定成本
Sheet「敏感性」
  销量变化率 / 单价变化率 / 净利润
  每个组合行引用假设，按变化率计算：
  收入：=假设!B2*(1+$A2)*假设!B3*(1+$B2)
  净利润：=收入-变动成本-固定成本
```

- 变化率用 `percent` 格式存小数（-10% 存 -0.1）。
- 组合 ≤10 行，避免数据表过大。

## 6. 口径与审计

适合：需要可追溯的分析交付。

```
Sheet「口径说明」
  指标 / 定义 / 数据来源 / 更新时间 / 备注
Sheet「原始数据」
  原始导入数据（只读不改）
Sheet「计算」
  只写引用原始数据的公式
```

- 原始数据与计算分离，审查者能追到每个数字的来源。
- 交付前 `read_xlsx` 验证：公式在、表名对、关键值和源数据一致。

## 7. 分组汇总与透视（参考 Doubao sheet）

- **分组汇总优先用原生透视/汇总能力**：在支持透视表的平台优先让用户拿到可交互透视；本工作模式用 `SUMIF`/`COUNTIF`/`AVERAGEIF` 汇总表时，保证维度唯一、公式可审计，并且不把公式汇总表伪装成原生透视表。
- **透视/汇总数据源要干净**：明细数据中间不插空行、不用合并单元格；日期按年/季/月/周分组时，先在明细或辅助列生成可排序的分组字段，再汇总。
- **汇总前先定口径**：求和/计数/去重数/平均值要先说清；写 `SUMIF`/`COUNTIF` 前确认范围起点跳过表头、终点覆盖真实末行。
- **汇总结果要能对账**：每个汇总 sheet 的总计与明细合计用公式勾稽；交付前 `read_xlsx` 抽查维度数和关键分组值，避免漏掉表尾数据。
- **维度列保持唯一词**：分组维度值必须统一（如“华东/华东大区”混用会拆组），必要时先用 `transform_file` 做清洗/映射。

## 从分析到 Workbook 的步骤

1. 选分析类型（趋势/对比/构成/异常/敏感性/口径审计）。
2. 确定需要的明细与汇总 sheet，写清列名/口径。
3. 写 Workbook JSON，公式优先，假设集中。
4. `read_xlsx` 抽查 + 在对话给结论和建议。

# Excel 故障排查（症状 → 修复）

按"用户看到的现象"查表。修复动作都是**改 Workbook JSON / 改 ops 后重新导出**，改完必须复验。

## 文件打不开 / 提示损坏

- **可能原因**：导出被中断；路径不是 .xlsx；被外部程序占用。
- **修复**：确认 `write_xlsx` 成功返回；`read_xlsx` 能无损读回说明包结构完整；仍打不开则重新导出一次。

## 公式不计算（显示 0 或空白）

- **可能原因**：公式写错引用（列号/行号不对、跨表表名写错）；公式所在列被当成文本（单元格是字符串但没以 = 开头）。
- **修复**：`read_xlsx` 读回看公式原文；SUM 区域是否连续（中间有空行会断区）；跨表引用确认表名一致（含空格用单引号：`'销售数据'!D2`）。

## 百分比显示成 800%（或 0.08 显示 0）

- **可能原因**：值存了 8 而不是 0.08；或该列没配 `percent` 格式。
- **修复**：比率值一律存小数（0.08 = 8%），列 formats 配 `"percent"`。

## 日期显示成一串数字（序列号）

- **可能原因**：值传了文本日期（如 "2026-03-21" 字符串）而不是 Excel 日期序列号；或列没配 `date` 格式。
- **修复**：日期列用 `"date"` 格式；值若是文本日期字符串，说明当前不支持自动转换——建议用文本列展示日期，或由公式生成日期。

## 金额显示成 1.2E+07 / 小数丢失

- **可能原因**：数值太大（>1e15）或没配 money/number 格式。
- **修复**：金额列配 `"money"`/`"number"`（千分位两位小数）；大数换单位（元→万元）写进表头，避免精度问题。

## 年份显示成 2,024

- **可能原因**：年份列用了默认千分位或 int 格式。
- **修复**：年份列 formats 配 `"year"`（`0` 格式，不加千分位）。

## 长数字（身份证/订单号）变科学计数

- **可能原因**：数值以数字类型存储，Excel 对大数自动转科学计数。
- **修复**：这类标识号应作为**文本**存储（字符串），不要转数字；配 `"text"` 格式。

## 外来 xlsx 打开后样式/合并/图表全没了

- **说明**：外来文件是近似导入（只还原数值/文本/公式），样式、合并单元格、图表数据不保留——这是边界内行为，**不是 bug**。
- **修复**：编辑外来文件前 read_xlsx 说明会提示；需要保留原样式的场景，让用户在 Excel/WPS 里手动改，或用本工具重建一个干净的版本。

## 用户要的效果做不出来（合并单元格/条件格式/数据验证/图表/保护）

- **说明**：不在能力边界内（见 SKILL.md）。**不要假装支持**。
- **修复**：明确告知不支持并给替代：防呆需求 → 表头写填写规范；样式需求 → 交付说明里描述期望样式；图表 → 用 write_pptx 的 chart 页表达数据趋势。

## 打开后数字格式显示不对（比如 ¥ 变乱码）

- **可能原因**：极少数老 Excel 版本对货币符号处理不同。
- **修复**：确认列 formats 是 `"money"`；如用户环境异常，改用 `"number"`（无货币符号）并说明。

## 修复已有 xlsx 的标准工作流（参考 qwenwork/workbuddy xlsx 修复类能力）

1. **先读后改**：`read_xlsx(path)` 拿当前 Workbook JSON（表名/行/列/公式/格式）。
2. **定位问题**：按用户反馈列出具体问题（哪个 sheet、哪一行/列、什么现象：公式错/数字格式错/数据错/需要加行）。
3. **小改**：用 `edit_xlsx` 改单元格 `set_cell`、改表头 `set_header`、加/删/改行 `add_row`/`delete_row`/`update_row`、加/删/移表 `add_sheet`/`delete_sheet`/`move_sheet`、改表名 `set_sheet_name`、全局改词 `replace_text`。
4. **公式修复**：`read_xlsx` 看公式原文，核对行列号/表名/SUM 区域；有表头时 `row:1` 对应 Excel 第 2 行，公式引用要 +1。
5. **结构调整**：没有 `add_column` 时，小表用 `update_row` 逐行补列 + `set_header`；大表重建 Workbook JSON 后重新导出。
6. **复验**：`read_xlsx` 抽查表名/行数/关键值/公式；外来文件改前确认备份存在。

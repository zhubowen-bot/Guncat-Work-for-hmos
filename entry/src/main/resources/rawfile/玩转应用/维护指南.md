# 玩转应用 · 维护指南

这个文件夹是应用内「玩转应用」弹窗展示的本地网页，不需要联网即可打开。
多页结构：**首页 = 大标题 + 目录**；目录点进去是一个**独立子页**（返回按钮 + 页名 + 该组卡片）。

## 文件结构

```
rawfile/玩转应用/
├── index.html        全部页面：首页(view-home) + 一个个子页(view-xxx)
├── assets/
│   ├── style.css     全部样式：颜色、圆角、多页视图、深色模式
│   └── app-icon.png  顶部应用图标（换图直接替换此文件）
└── 维护指南.md       本文件
```

## 页面是怎么"翻页"的

index.html 里每个 `<section class="view" id="view-xxx">…</section>` 就是一页。
首页是 `view-home`（只有大标题 + 目录），其余都是子页。
页面底部有一小段固定脚本：目录卡片 `href="#/xxx"` ↔ 显示 `view-xxx`，
点子页左上角的返回按钮（`href="#/"`）回首页。这段脚本不用动。

## 常见修改

### 改一条功能的文字
找到对应的 `<!-- 功能: xxx -->` 注释，只改里面的文字即可：

```html
<div class="card">
  <div class="card-icon">
    <svg viewBox="0 0 24 24">…</svg>
  </div>
  <div class="card-body">
    <div class="card-title">这里改标题</div>
    <div class="card-text">这里改描述文字。</div>
  </div>
</div>
```

### 加一条功能
复制上面任意一个 `<div class="card">…</div>` 整块，粘贴到目标子页里，改成新的文字。

- 图标是单色实心 SVG（浅色模式自动黑、深色模式自动白），不需要设置颜色。
- 不想要图标时，把 `<div class="card-icon">…</div>` 整块删掉。
- 功能行没有右侧箭头（箭头只在会跳转的目录条目上）。
- 想换图标：去 https://fonts.google.com/icons 选 **Filled** 风格，
  复制 SVG 里的 `path d="…"` 替换即可。

### 子页顶部的图片轮播（图和介绍卡一一对应）
每个子页顶栏下面是一个轮播板块：手指左右滑动切换、圆点指示当前张。
**轮播里的每张图，对应下面的一张介绍卡**——滑到第几张图，
下面就只显示第几张卡的标题和描述；卡片之间不放分隔线。

结构是"图在前、卡在后"，数量必须一致、顺序一一对应：

```html
<div class="gallery">
  <div class="gallery-track">
    <img src="assets/截图1.png" alt="">   ← 第 1 张图
    <img src="assets/截图2.png" alt="">   ← 第 2 张图
  </div>
  <div class="gallery-dots"></div>
</div>

<div class="gallery-cards">
  <div class="card">…介绍卡 1…</div>      ← 对应第 1 张图
  <div class="card">…介绍卡 2…</div>      ← 对应第 2 张图
</div>
```

- 想加一对：在 `gallery-track` 里加一行 `<img>`，再在 `gallery-cards` 里加一个
  `<div class="card">…</div>`，**位置对齐**即可；删减同理，两边一起删。
- 图片比例不限：手机竖图、电脑横图都可以，宽度约为内容区的 2/3、高度按图片自身比例；
  **每一张都会居中显示**（含第一张和最后一张），滑动时两侧对称露出相邻图片的边缘。
  图片文件放进 `assets/` 目录，改 `<img src>` 即可；PNG 的透明区域会直接透出页面背景，
  需要底色就把颜色画进图片里。

### 长文本卡片（整段介绍用）
在 `class="card"` 后面加 `card-prose`：

```html
<div class="card card-prose">
  <div class="card-body">
    <div class="card-title">标题</div>
    <div class="card-text">整段介绍文字……</div>
  </div>
</div>
```

- 图标自动置顶与标题对齐（不会悬空在中间）。

### 新增一页
1. 复制整个 `<section class="view" id="view-xxx">…</section>` 块（比如复制"实用技巧"那页），
   粘贴到最后一个 `</section>` 之后。
2. 改两处：`id="view-xxx"`（xxx 起个不重复的名字）和顶栏 `.pagebar-title` 的页名。
3. 到首页目录面板里复制一个 `<a class="card" href="#/xxx">` 目录项，`href` 填 `#/xxx`。

### 调整全局配色 / 圆角
全部在 `assets/style.css` 顶部的「设计变量」区（`:root { … }`），组件样式不需要动：
- `--hero-wash`：顶部渐变晕染色（铺满窗口宽）
- `--divider`：行分隔线
- `--icon`：功能行图标颜色（深色模式自动换色）
深色模式的变量在同文件底部的 `@media (prefers-color-scheme: dark)` 中。

### 更换顶部应用图标
顶部用的是 `assets/app-icon.png`（应用图标的压缩副本，192×192）。
换新图标时压缩到 200px 左右覆盖此文件即可，页面代码不用改。

## 注意事项

- 弹窗入口与打开逻辑在 `entry/src/main/ets/views/PlayGuidePanel.ets`，
  其中 `$rawfile('玩转应用/index.html')` 指向本页面，改文件名需同步修改。
- 页面会跟随系统自动切换深浅色，无需额外处理。
- 每次在应用内重新打开弹窗都会回到首页，属正常现象。

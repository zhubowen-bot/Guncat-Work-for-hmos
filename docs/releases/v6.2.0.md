# Guncat Work 6.2.0

> 鸿蒙掌上 Codex —— ArkTS / ArkUI 从零构建的原生 HarmonyOS AI 客户端，模块化 Agent Loop 内核 + 三协议流式对话 + 内置工具与技能库，完整对标 PC 端 Agent 工作台。

**版本** `6.2.0`（versionCode 700） · **commit** `9fd283e` · **日期** 2026-09-24

这是工作模式（Agent Loop）走向完整形态的一个版本：**产物可核对、代码可执行、办公文档成套生成、技能库成体系、长任务更稳**。

---

## ✨ 本版亮点

### 1. Codex 风格产物卡片
任务结束后，生成 / 改动的文件在对话流末尾以「产物」卡片汇总，默认展开；每个文件带行级 diff 缩略，默认折叠、可单独展开；任务结束自动滚到底部，无需手动下翻。
→ 长任务交付第一次做到「一眼看清改了什么」。

### 2. 工作区文件就地预览 + 一键分享
产物卡片、工作区弹层、右侧详情面板中的文件均可点击，通过 HarmonyOS Preview Kit 就地预览，或一键走系统分享面板分享原始文件——不暴露路径、不打包、不选格式。
Preview Kit 不支持的格式（如 `.md`）会直接拉起系统「打开方式」选择框，用已安装的应用打开。

### 3. `run_js`：设备本机的 JS 执行沙箱
基于 **JSVM-API** 的独立 JS 引擎沙箱，智能体可现场写代码做计算——数据清洗、正则提取、统计汇总、程序化生成结构化数据，产出直接写回工作区，再交给 `write_docx` / `write_xlsx` / `write_pptx` 成文。
沙箱不联网、不读写文件系统（文件由宿主显式预载与落盘），在后台线程执行并有超时保护。这是在无 shell 环境下补齐「执行代码」能力的关键一环。

### 4. Office 三件套 + 32 个技能
PPT / Word / Excel 全套办公技能正式上线，全部基于 **JSON 中间层 + 确定性导出器**，文档可无损读回、算子式编辑。
技能库扩展到 **32 个**（5 个主 Skill 路由 + 7 个格式分支），移植自四大主流 AI 工作平台并完成本项目工具适配：论文转换、法律检索、学术出版、内容写作、专利撰写、行业分析、营销策划、舆情追踪……
PPT 生成质量升级到 V3.1：默认篇幅 20 页以上，每页必须带装饰性 SVG / 纹理背景与内容配图，内置科技 / 古风 / 简约 / 杂志 / 商务 / 学术 / 路演等视觉风格。

### 5. 内置本地联网搜索
软件内置，无需手动开关，工作模式与聊天模式都能调用——联网能力不再受制于服务端联网开关。

### 6. 长任务更稳、更好排查
- 限流或网络抖动自动重试，不用重来；任务过长自动整理历史，重要信息不丢
- 工具调用加入超时、取消与参数校验，出错更快暴露
- 核心循环换成新的「驱动引擎」（状态机 + 计划器，默认启用），日志可看清每步决策；异常可一键回退旧循环
- 每次工具调用的耗时、接入协议、是否重试均有记录
- 子代理支持并行派发（全局并发上限 4），并默认获得独立产出目录，并行任务不再互相覆盖文件
- 支持外挂插件与技能，按需扩展能力

### 7. 其他修复与增强
- 修复 Anthropic 协议中偶发的传参错误与文本过长截断
- 新增后缀补全开关，便于非标准地址接入
- 对话历史改为文件存储（`filesDir/guncat_conversations.json`），长历史不再受 Preferences 16MB 单值上限约束；首次启动自动迁移旧数据
- 修复删除 / 新建会话后侧边栏不实时刷新
- 修复工作模式下通过系统分享发来的文件不进沙箱工作区

## 📦 安装

本 Release **暂不提供预编译 HAP**，请从源码构建。

**环境要求**
- DevEco Studio 6.0.1 或兼容版本
- HarmonyOS SDK API 24（6.1.1）
- HarmonyOS 手机真机

**构建**

```bash
hvigorw --mode module -p product=default -p module=entry@default -p buildMode=debug assembleHap
```

或用 DevEco Studio 打开仓库根目录 → 配置签名 → 运行 `entry` 模块。

**首次使用**：打开设置 → 新建 API 配置 → 填写接入方式（OpenAI Completions / OpenAI Responses / Anthropic Messages）、Base URL、API Key、模型名 → 回到对话。

常用兼容地址：
- DeepSeek Responses：`https://api.deepseek.com`
- 火山方舟 Responses：`https://ark.cn-beijing.volces.com/api/v3`
- Anthropic Messages：`https://api.anthropic.com/v1`

## ⚠️ 已知限制

- 需要 HarmonyOS 真机；模拟器上 Preview Kit / Share Kit / CoreSpeechKit 等系统能力行为不一致
- 联网搜索、图片理解等能力取决于你所配置的模型服务是否支持
- 朗读可用音色及是否需要下载由设备与系统版本决定
- 交互模式（Intelligent UI）在 6.3.0 才引入，本版不含

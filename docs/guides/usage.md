# 使用指南

> [← 返回 README](../../README.md)


## 基本对话

1. 首次启动后打开设置，进入「模型 → 模型配置」。
2. 新建或选择 API 配置，填写接入方式、Base URL、API Key 和模型名称；修改会自动保存，无需手动点保存。
3. 从侧边栏选择智能体。
4. 输入消息并发送。

## 设置与用量

1. 设置是独立页面，一级分组为「模型」（模型配置 / 高级参数 / 用量与成本）、「能力」（个性化指令 / 能力调度 / 本地联网搜索 / 多模态解析）、「声音」（朗读）、「系统」（终端 / 工具 / 检查更新）。
2. 模型配置 / 高级参数 / 本地联网搜索 / 多模态解析分页共享同一份草稿，输入后自动防抖保存；返回或切换配置方案前会再同步一次，避免输入丢失。
3. 「用量与成本」展示本月等价成本、今日 / 近 7 天 / 全部汇总与 53 周热力图；账本保留最近 400 天按日明细（更早只留全部累计值），可切换费用 / Token / 请求数、筛选服务商、设置月预算、导出 CSV 或清空统计。
4. 「工具」是只读目录，按阅读与检索、写入与编辑、计算与执行、文档产出、联网与上下文、任务与协作、技能七组列出全部 47 项工具，不提供开关。
5. 「终端」只读展示原生 Shell、原生 CPython 3.12、应用版本、系统版本、API 等级、设备类型、芯片平台与指令集。
6. 「检查更新」优先通过 `apptest://` 打开 AppTest 公开测试页；未安装 AppTest 时回退官方公开链接。
7. 「个性化指令」在「能力」组第一行：点右上角「新建」，或点已有条目进入编辑页。名称可选；指令正文最多 8000 字，支持 Markdown；点「Markdown 渲染」在原文编辑和渲染预览之间切换，默认不渲染，渲染只影响预览，保存的始终是原文。在「生效范围」里勾选交互模式、工作模式和聊天引擎，新建时默认勾选前两者，至少选一个才能保存；点「添加」/「保存」后从下一次请求开始自动拼进所选范围的系统提示词末尾。编辑时可删除（二次确认），有未保存修改时返回会提示放弃编辑。

## 添加图片或文件

### 聊天模式

1. 点击输入框旁的附件按钮。
2. 从图片选择器或文件选择器选择内容。
3. 等待预解析完成；关闭预解析时，附件会在发送时直接传给支持多模态的接口。
4. 检查待发送附件后，由用户主动发送。

### 工作模式 / 交互模式

这两个模式共用同一个沙箱工作区，**文件只进工作区，不进待发送附件**（上传、拍照都是直接落盘；发送时模型从工作区读取，图片用 `view_image` 看）：

1. 点工作区面板的「上传」挑文件，或点输入框旁的拍照按钮——照片直接存入工作区。
2. 在输入框描述任务/问题，模型按运行时快照里的工作区文件树读取素材。

系统分享到这时的处理：内容会放进待发送附件区**暂存**，同时写一份进当前会话的工作区——所以切回聊天模式后它仍能作为附件发出，而留在工作/交互模式发送时只以工作区文件送达（不会再重复当附件发一遍）。若分享时还在聊天模式，则只暂存；之后切到工作/交互模式发送时会先补写进工作区。

也可以在图库或文件管理器中选择内容，通过系统“分享”选择 Guncat Work，不会自动提交请求。

### 附件直传策略

- OpenAI Completions：小图使用 `image_url` 内联，大图自动上传 Files API 后使用 `file` + `file_id`；文档使用 `file_url`。
- Anthropic Messages：小图使用 base64 `image` 内容块内联，大图自动上传 Files API 后使用 `source.type = file` + `file_id`；文档会发送 `document` 块。
- OpenAI Responses：
  - 小图（≤4MB）：Base64 内联发送。
  - 大图（>4MB）：自动上传 Files API，使用 `input_image.file_id`。
  - 文档：自动上传 Files API 后使用 `input_file.file_id`，或内联 `input_file.file_data`。
  - 上传失败会自动回退 Base64。
- 如果服务商不支持某种文档/图片块，服务端会返回错误；应用会原样展示错误，不会在客户端擅自丢弃。

## 深度思考

按钮按接入协议显式控制，不按服务商猜参数：

- **OpenAI Completions**：`thinking.type = enabled / disabled`，开启时另发 `reasoning_effort = high`。
- **Anthropic Messages**：`thinking.type = enabled / disabled`，开启时另发 `output_config.effort = high`。
- **OpenAI Responses**：`reasoning.effort = high / none`（`none` 表示关闭）。
- 按钮状态优先于额外请求参数，避免界面状态与实际请求不一致。
- 历史思考会跨轮次按协议回传：Completions 的 `reasoning_content`、Anthropic 的 `thinking` 块与签名、Responses 的 reasoning output item；历史被修剪或压缩后失效的签名会先清掉。

## 工作模式

1. 点空态大标题处的「工作模式」一档即可换挡（应用启动默认落在交互模式；也可以走窄屏抽屉「Agent引擎（推荐）」或宽屏侧栏「引擎」分组的 🛠「工作模式」，它排在 ✦「交互模式」下方），主页面标题与空态随之切换为工作模式。
2. 需要材料时通过工作区面板「上传」添加文件（或用拍照按钮，照片直接进入工作区）。
3. 在输入框描述任务；复杂任务 Agent 会先建立任务清单，再逐项调用工具执行，时间线中可实时查看每一步。
4. 产出物直接是手机可读格式：报告→`docx`、表格→`xlsx`、演示文稿→`pptx`（支持指定主题、图表、编辑已有 PPT；Agent 会自动加载内置的 PPT 技能按规范制作）。
5. 点击任意工具步骤可展开查看参数与执行结果；右上角「导出」把整个工作区打包为 `.zip` 保存。
6. 完成后 Agent 输出详尽总结（含产出文件路径）；侧边栏切换到其他智能体即退出工作模式，工作会话与工作区文件保留。

## 交互模式（Intelligent UI）

1. 打开应用默认进入交互模式；也可以随时用空态大标题处的「交互模式 / 工作模式」胶囊换挡（另一条路是窄屏抽屉「Agent引擎（推荐）」或宽屏侧栏「引擎」分组的 ✦「交互模式」项）。
2. 顶部的模型胶囊可切换模型，并在「能力预设」里选择**思考强度**：均衡(High) / 快速(Low) / 关闭(Off)。交互模式没有 极高(Max)（交付物是界面，长思考收益低），**默认就是「快速(Low)」**，也可以选「关闭」更快；该档位与工作模式的档位各自保存、互不影响。
3. 像平时一样提问即可，例如「帮我算一下 30 万房贷在不同利率下的月供」「对比这三个方案的收益并让我调参数」「把这段数据做成能筛选的表格」。**默认一次回答直接给界面、不调用任何工具**；只有界面里的数字必须来自工作区真实数据时才破例读一次文件或算一次（所以问它问题响应很快）。
4. Agent 不做长篇文字回答，而是**输出一份界面程序**，应用把它渲染成原生界面：标题/正文、图表（柱状 / 折线 / 面积 / 横向条 / 饼环 / 径向 / 雷达 / 堆叠条）、表格、指标卡、图片墙、选项卡 / 折叠面板 / 步骤条、以及整套表单控件。
5. **本地交互即时生效**：拖动滑块、切换开关、点选项、填输入框——表达式里的 `$变量` 会立刻用新值重算，界面（含图表与数值文案）随之刷新，**不发请求、不等模型**。
6. **需要重算时点按钮**：形如「换口径重算」的按钮会把你的设置 + 诉求打包成一条消息回传，Agent 立即产出**更新后的完整界面**；表单提交会把全部字段值一起带上。
7. 界面在生成过程中**渐进成形**（第一行的 `root = Card([...])` 就让外壳出现，后面的语句逐条补齐），未写完时控件置灰；输出被截断时已写完的部分照常渲染，底部标注「界面未写完」。
8. 只有最新一条界面可交互（历史界面自动置灰归档），避免改到旧参数上；你调过的参数会随消息保存，滚动、切会话、重启后仍在，并在下一轮告诉模型。
9. 需要材料时和工作模式一样：通过胶囊的「交互界面」面板上传文件（进入沙箱工作区）。交互模式基础工具面是裁剪后的 **27 个**工具（读素材 / 算真实数字 / 核实外部事实 / 出文件）；能力调度里偏检索/多阶段的档位会追加 `record_search`、`todo_write`（详见下面「能力调度」）。`goal_*`、`schedule_*`、`subagent` 等长程工具始终不会出现在请求里。
10. 需要正式文件（Word / Excel / PPT）时直接说，Agent 会照常落盘产出——交互模式并不取消文件能力。
11. 想排查模型到底写了什么：界面底部「查看原始输出」可展开源码；有解析诊断时会显示「诊断 · N 条」。

### 能力调度（交互模式的提示词档位）

1. 设置 →「能力」→「能力调度」，在九个档位里选一个：**轻简 / 效率 / 专家 / 经典 / 论文转换 / 法律检索 / 深度研究 / 信息筛滤 / LLM评估**；默认「轻简」。
2. **轻简**就是原来的交互模式：默认零工具、思考短、一句话直接出界面，最快。其余八档把原聊天引擎里对应智能体的成熟提示词正文搬了过来（效率=3.0-Flash、专家=3.0-Pro、经典=2.5-lite、论文转换=Cnvt-Paper、法律检索=Srch-Law、深度研究=Srch-Research、信息筛滤=Srch-Sift、LLM评估=Eval-LLM），只换了交付形态（回答仍是可操作界面）与工具通道。日常问答留在轻简即可；写论文、查法条、做深度调研、评估模型时再切到对应档位。
3. **档位越靠后越"重"**：系统提示词更长（轻简约 2.2 万字符、专家约 8.5 万字符）、思考更深、首答会更慢，但内容更完整、专业流程更严格。切档会**同时把思考强度调到该档推荐值**（轻简/效率/论文=快速，其余=均衡），之后仍可在模型弹层的「能力预设」里手动改。
4. 档位**只影响交互模式**，工作模式与聊天模式不受影响；选择会记住，下次继续用。
5. 档位还会改变下发的工具面：轻简与论文转换保持 27 个；效率 / 经典 / 信息筛滤追加 `record_search`（把检索结论和来源记到工作区 `.searches.md`，便于多次检索后回溯）；专家 / 法律检索 / 深度研究 / LLM评估再追加 `todo_write`（多阶段任务清单）。长程维护类工具（`goal_*`、`schedule_*`、`subagent` 等）在任何档位都不下发。
6. 想查看每个档位**组合后的完整提示词**（用来核对或提修改意见）：九份全文在 `docs/prompts/interactive-tiers/`，分层与逐档适配说明在 `docs/prompts/interactive-tier-adaptation.md`。

## 朗读

1. 设置「声音 → 朗读」可开启自动朗读；对话页右上角的开关与设置共用同一状态。关闭自动朗读后，仍可点击助手消息的朗读操作手动朗读。
2. 在悬浮控制条中暂停/继续、切换语速或音色。
3. 拖动进度条可从相应文本位置继续朗读。
4. 拖动控制条空白区域可调整位置。
5. 点击关闭按钮结束朗读并收起控制条。

## 对话与消息操作

- 在侧边栏中新建、切换或删除对话。
- 复制助手消息内容。
- 对助手消息执行重新生成。
- 点击图片进入大图预览。
- 生成过程中可停止当前请求。

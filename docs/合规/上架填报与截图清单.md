# 上架填报与截图清单

> 配套文档：`AI生成合成内容标识说明.md`<br>
> 适用版本：Guncat Work `7.3.0`

---

## 1. 华为应用市场填报口径

### 1.1 是否提供人工智能生成合成服务

**建议选择：是。**

原因：应用提供 AI 对话、AI 写作、AI 文档/演示文稿/表格生成、AI 绘图等功能，用户可以在应用内生成并复制、导出这些内容。即使模型服务由用户自行配置，应用仍然提供了生成合成内容的交互与交付能力，应按《人工智能生成合成内容标识办法》提交标识材料。

### 1.2 是否接入第三方大模型

**建议选择：否（不内置、不代理、不转售）。**

补充说明可直接使用：

> 本应用不内置大模型、不包含模型权重或开发者持有的 API Key，也不通过开发者服务器代理模型请求。用户在应用设置中自行填写 OpenAI Completions / OpenAI Responses / Anthropic Messages 兼容服务的 Base URL、API Key 和模型名，请求由用户设备直接发送到其选择的服务商。应用可能提供常见服务商的 Base URL 预设或占位提示，但不含可用 Key；模型服务由用户自行选择并承担相应责任。

### 1.3 是否提供生成内容的导出/下载

**建议选择：是。**

应用提供：

- 复制回答（纯文本 / Markdown）；
- 导出 Word；
- 生成 Word / PowerPoint / Excel / SVG 文件；
- 分享工作区文件；
- 工作区 ZIP 打包导出。

因此需要提交《人工智能生成合成内容标识说明函》和相应截图，而不是只提交应用内显式标识截图。

### 1.4 其他能力声明

- 不提供合成人声、仿声、人脸生成/替换/操控、姿态操控、沉浸式拟真场景；
- 不生成或导出音频、视频文件；朗读使用系统 TTS 播放 AI 文本，不提供音色克隆/仿声；
- 不提供 AI 换脸、AI 拟声等深度合成功能。

## 2. 截图清单

建议按以下顺序截图，文件名使用 `01-对话显式标识.png` 这种编号，方便审核对照。

| 编号 | 截图内容 | 操作步骤 | 画面中应看到 |
| --- | --- | --- | --- |
| 01 | 对话模式回答 | 在对话模式发送一个普通问题，等待回答完成 | 回答正文末尾 `AI生成` 角标 |
| 02 | 工作模式最终回答 | 切到工作模式，完成一个简单任务，等待最终回答 | 最终回答正文末尾 `AI生成` 角标；产物卡片标题旁 `AI生成` |
| 03 | 交互模式界面 | 在交互模式生成一张可操作界面 | 交互消息末尾 `AI生成` 角标 |
| 04 | 复制纯文本 | 点回答下方「文本」按钮，粘贴到系统备忘录 | 粘贴内容末尾有 `AI生成` |
| 05 | 复制 Markdown | 点回答下方「MD」按钮，粘贴到文本编辑器 | 粘贴内容末尾有 `> AI生成` |
| 06 | 导出 Word | 点回答下方「Word」，保存并打开 | 正文末尾、每页页脚有 `AI生成`；文件属性中可见 AIGC 自定义属性 |
| 07 | 生成 PowerPoint | 让工作模式生成一份 `.pptx`，打开第一页 | 每页左下角有 `AI生成`；文件属性中可见 AIGC 自定义属性 |
| 08 | 生成 Excel | 让工作模式生成一份 `.xlsx`，切到页面布局/打印预览 | 页脚左下角有 `AI生成`；文件属性中可见 AIGC 自定义属性 |
| 09 | 生成 SVG | 让工作模式生成一张 `.svg`，用预览器打开 | 图片右下角有 `AI生成`；用文本编辑器打开可见 `<metadata id="aigc-mark">` |
| 10 | 工作区 ZIP | 导出工作区 ZIP，解压 | 根目录有 `_AI生成内容标识.txt`，内容包含生成合成标签、提供者、制作编号 |
| 11 | 合规与许可页 | 打开设置 →「系统」→「合规与许可」 | 显示 AI 生成内容标识、第三方组件与许可、开源许可证全文入口 |
| 12 | 隐式标识证明 | 将 `.docx` 改名为 `.zip` 后解压，打开 `docProps/custom.xml` | 可见 `name="AIGC"` 和 JSON 字段 `Label` / `ContentProducer` / `ProduceID` |

> 截图要求：画面清晰、完整，能看出是同一应用；不要只截局部文字导致无法证明上下文。涉及文件属性的截图，建议同时保留文件名和属性窗口。

## 3. 文件样例清单

建议准备以下样例（可放在同一目录，文件名与截图对应）：

- `sample.docx`：由对话回答导出或工作模式生成；
- `sample.pptx`：由工作模式生成；
- `sample.xlsx`：由工作模式生成；
- `sample.svg`：由工作模式生成；
- `sample.png`：由 SVG 生成的预览图；
- `sample.md`：复制 Markdown 后保存的文本；
- `工作区导出.zip`：工作区打包导出。

每个样例都应能通过：

```bash
python tools/check-aigc-mark.py sample.docx sample.pptx sample.xlsx sample.svg sample.png sample.md
```

## 4. 说明函填写要点

- 应用名称必须与提交审核的应用名称一致（当前为 `Guncat Work`，以应用市场实际名称为准）；
- 开发者名称必须与应用市场开发者主体一致；
- 需加盖公章；
- 多个人工智能生成场景分别列出：对话/工作模式文本、交互界面、Word、PowerPoint、Excel、SVG、工作区 ZIP；
- 显式标识与隐式标识分别描述，隐式标识给出 `AIGC` 字段样例；
- 说明“模型服务由用户自行配置、不内置第三方大模型”的事实，避免审核误判为开发者自营模型服务。

模板见 `人工智能生成合成内容标识说明函-模板.md`。

## 5. 常见退回原因与规避

| 退回原因 | 规避方式 |
| --- | --- |
| 只提交了应用内截图，没有说明导出文件的隐式标识 | 同时提交说明函、Office/SVG 样例和 `custom.xml` 截图 |
| 说明函中的应用名/公司名与提交主体不一致 | 按应用市场后台的名称逐字填写，并加盖公章 |
| 截图看不到 `AI生成` 字样 | 使用本文档第 2 节的 01–12 截图，确保角标、页脚、图片右下角都入镜 |
| 应用声明“不含第三方大模型”，但截图里出现模型名 | 在说明中写清“模型服务由用户自行配置”，截图只展示设置入口，不展示开发者自有 Key |
| 导出文件打不开 | 提交前用 Word / PowerPoint / Excel / 浏览器分别打开样例，确认无损坏 |
| 只说明文本，遗漏图片/表格 | 在说明函中逐一列出文本、界面、Word、PPT、Excel、SVG、ZIP |

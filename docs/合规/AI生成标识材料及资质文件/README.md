## 提交前必查

1. **包名要统一。** 说明函里目前写的是 `com.bowenapp.guncatai`，当前仓库 `AppScope/app.json5` 是 `com.bowenapp.guncataibeta`。提交前确认最终包名；如果正式包是 `com.bowenapp.guncatai`，需要同步修改 `AigcMark.PRODUCER_CODE` / `PROPAGATOR_CODE` 并重新导出样例。
2. **说明函走本地。** `00-说明函/` 含姓名、手机号、邮箱等个人信息，已加入 `.gitignore`，不要取消忽略或上传公开仓库。身份证号行是否必须填写，以平台要求为准；没有明确要求时建议用“不含身份证”版本。
3. **第 12 张不能只用附录 E。** 必须是导出文件里 `docProps/custom.xml` 的截图；`附录E 文件元数据隐式标识格式.docx` 只是格式参考。
4. **样例自检。** 发布前重新跑一次：

```bash
python tools/check-aigc-mark.py \
  "docs/合规/AI生成标识材料及资质文件/04-生成样例/06-Word样例.docx" \
  "docs/合规/AI生成标识材料及资质文件/04-生成样例/07-PowerPoint样例.pptx" \
  "docs/合规/AI生成标识材料及资质文件/04-生成样例/08-Excel样例.xlsx" \
  "docs/合规/AI生成标识材料及资质文件/04-生成样例/09-SVG样例.svg"
```

5. **说明函签名。** 个人开发者不需要公章：打印后本人手写签名，再扫描 PDF 提交。

## 备注

- 本文件夹只放提交材料，不放代码或构建产物。
- 截图和样例来自当前 `7.3.0` 版本；如果版本号或导出行为变化，需要重新截图并重新生成样例。

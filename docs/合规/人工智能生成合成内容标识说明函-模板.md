## 二、服务形态说明

1. 本应用是 HarmonyOS 原生 AI 工作台，提供对话、工作模式（Agent Loop）和交互模式（Intelligent UI），可生成文本、表格、文档、演示文稿和 SVG 图片等内容。
2. **本应用不内置、不代理、不转售任何大模型服务，不包含模型权重或开发者持有的模型 API Key。** 模型服务由用户在应用设置中自行配置：用户填写其选择的服务商 Base URL、API Key 与模型名，请求由用户设备直接发送至该服务商，不经过开发者服务器。应用可能提供常见服务商的 Base URL 预设或占位提示，但不含可用 Key。
3. 本应用不提供合成人声/仿声、人脸生成/替换/操控、姿态操控、沉浸式拟真场景等深度合成能力，不生成或导出音频、视频文件；朗读使用系统 TTS 播放 AI 文本，不提供音色克隆/仿声。
4. 本应用对 AI 生成内容添加显式标识和隐式标识，具体如下。

## 三、显式标识

| 场景                       | 标识位置与形式                           |
| ------------------------ | --------------------------------- |
| 对话模式回答                   | 回答正文末尾 `AI生成` 角标                  |
| 工作模式最终回答                 | 最终回答正文末尾 `AI生成` 角标                |
| 交互模式消息                   | 交互消息末尾 `AI生成` 角标                  |
| 复制纯文本                    | 文本末尾追加 `AI生成`                     |
| 复制 Markdown              | 文本末尾追加 `> AI生成`                   |
| 导出 Word                  | 正文末尾与每页页脚显示 8pt 浅灰 `AI生成`         |
| 生成 PowerPoint            | 每页左下角显示 8pt 浅灰 `AI生成`             |
| 生成 Excel                 | 页面布局/打印页脚左下角显示 `AI生成`             |
| 生成 SVG                   | 图片右下角显示 `AI生成`，字号不低于最短边的 5%，带白色描边 |
| 工作区 ZIP 导出               | 压缩包根目录附 `_AI生成内容标识.txt` 说明文件      |
| 分享 Markdown/纯文本/SVG/HTML | 使用带标识的临时副本，原文件不修改                 |

上述文字提示均同时包含“AI”与“生成”两个要素，符合《人工智能生成合成内容标识办法》对文字提示的要求。

## 四、隐式标识

1. 生成的 `.docx`、`.pptx`、`.xlsx` 文件在 `docProps/custom.xml` 中写入名为 `AIGC` 的自定义属性，值为附录 E 规定的 JSON 字符串，每个文件仅保留一份。
2. 生成的 `.svg` 文件在根元素后写入 `<metadata id="aigc-mark">`，内容为同一份 AIGC JSON。
3. 字段示例：

```json
{"AIGC":{"Label":"1","ContentProducer":"Guncat Work (com.bowenapp.guncataibeta)","ProduceID":"GW-20261110123045-1a2b3c4d","ReservedCode1":"","ContentPropagator":"Guncat Work (com.bowenapp.guncataibeta)","PropagateID":"GW-20261110123045-1a2b3c4d","ReservedCode2":""}}
```

4. `Label` 取值为 `1`，表示属于人工智能生成合成内容；`ContentProducer` 为生成合成服务提供者名称/编码；`ProduceID` 为该内容的唯一制作编号；`ContentPropagator` 与 `PropagateID` 在首次写入时与制作者/制作编号一致。

## 五、导出与下载范围

本应用提供以下生成内容出口，均已按上述方式添加标识：

- 复制回答（纯文本 / Markdown）；
- 导出 Word；
- 生成 Word / PowerPoint / Excel / SVG 文件；
- 分享工作区文件；
- 工作区 ZIP 打包导出。

对于 CSV、JSON 等结构化数据文件，为保持文件可机读性，不在数据行中插入会破坏结构的标识；其 AI 生成属性在应用内角标、产物卡片和 ZIP 根目录说明文件中体现。
